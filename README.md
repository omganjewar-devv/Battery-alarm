# 🔋 MacBook Battery Alarm

A simple Python script that notifies you when your MacBook battery reaches 80% while charging.

## ✨ Features

- Monitors battery percentage.
- Checks battery status every 15 seconds.
- Sends a macOS notification at 80%.
- Plays an alert sound.
- Prevents repeated alerts during the same charging session.

## 🛠️ Requirements

- macOS
- Python 3
- MacBook with a battery
